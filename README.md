# 경력증명 자동화 v0.1

학교 경력대장 엑셀을 브라우저에서 불러와 오류를 점검하고, 필요한 경력을 선택해 경력증명서를 인쇄하는 정적 웹앱입니다.

## v0.1 기능

- `.xlsx`, `.xls` 경력대장 업로드
- `대장` 시트 우선 인식
- 성명·생년월일별 대상자 묶기
- 잘못된 날짜, 종료일 누락, 기간 역전, 중복·겹침 경고
- 오류가 없는 경력만 선택하여 증명서 생성
- 선택 경력 1~5건은 5줄, 6~10건은 10줄 서식 자동 적용
- 기존 엑셀과 같은 방식으로 경력별 연·월·일 계산 후 30일→1개월, 12개월→1년 환산
- 학교 기본정보 로컬 저장
- 대장 자료 웹 수정 및 수정본 엑셀 내려받기
- 브라우저 인쇄 및 PDF 저장

## 인식하는 대장 열

기본 열 이름은 다음과 같습니다.

`성명 / 생년월일 / 근무부서 / 직급(위) / 급제 / 시작일 / 종료일 / 기간 / 퇴직사유 / 비고`

선택 열: `소정근로시간`

열 이름의 일부 변형(이름, 직위, 부서, 임용일, 퇴직일 등)도 자동 인식합니다.

## 배포

### GitHub Pages

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 최상위에 올립니다.
3. Settings → Pages → Deploy from a branch를 선택합니다.
4. `main` / `/root`를 선택하고 저장합니다.

### Netlify

이 폴더 전체를 Netlify의 수동 배포 영역에 끌어다 놓습니다.

## 개인정보 주의

- 실제 경력대장 엑셀을 GitHub 저장소나 배포 폴더에 넣지 마세요.
- 업로드한 대장 자료는 서버로 보내지 않고 현재 브라우저 메모리에서만 사용합니다.
- 새로고침하면 업로드 자료가 사라집니다.
- 학교명·담당자·전화번호 설정만 브라우저 로컬 저장소에 저장합니다.
- 엑셀 읽기 기능은 SheetJS CDN을 사용하므로 처음 접속 시 인터넷 연결이 필요합니다. 엑셀의 내용 자체는 외부로 전송하지 않습니다.
