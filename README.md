# 경력증명 자동화 v0.3

학교 행정실에서 교육공무직·일용직, 기간제교원, 시간강사·전문강사 경력대장을 불러와 자료를 점검하고 경력증명서를 출력하는 정적 웹앱입니다.

## 지원 대장

### 교육공무직·일용직

- 성명
- 생년월일
- 근무부서
- 직종·직위 또는 직급(위)
- 고용형태 또는 급제
- 시작일
- 종료일
- 퇴직사유
- 소정근로시간
- 발령사항·비고·확인메모

### 기간제교원

- 직위(급)
- 과목
- 성명
- 생년월일 또는 주민번호
- 임용시작일
- 임용종료일
- 호봉 열이 있어도 업로드할 수 있습니다.

### 시간강사·전문강사

- 발령일자
- 소속
- 직위구분
- 담당구분
- 담당내용
- 성명
- 생년월일 또는 주민번호
- 임용시작일
- 임용종료일
- 주당수업시간
- 총주수
- 방학기간 제외
- 근무시간
- 발령근거·발령사항·비고·확인메모

시간강사 경력증명서의 법정 항목명은 `근무 기간`, `근무연수`, `직급(위)`, `근무부서`를 그대로 유지합니다. 세부정보는 다음처럼 기존 칸 안에서 조합합니다.

- 직급(위): `시간강사(주당6시간, 총34주)`
- 방학기간 제외: 직급(위) 다음 줄에 `방학기간제외`
- 근무부서: 교과는 `과목: 음악과`, 프로그램·부서는 담당내용 그대로 표시
- 최종직위 또는 직급: `시간강사(음악과)`

## 주요 기능

- 세 종류 엑셀 대장 자동 인식
- 성명·생년월일·주민등록번호 기준 대상자 묶기
- 경력 건별 선택 및 정상 경력 전체 선택
- 날짜 오류, 기간 역전, 누락, 중복, 기간 중첩 점검
- 시간강사 직위·담당구분·주당수업시간·총주수·방학 제외값 점검
- 일반·소정근로시간 포함·기간제교원·시간강사 경력증명서 발급
- 5줄·10줄 서식과 11건 이상 별지 자동 생성
- 주민등록번호 표시 선택 및 자료에 없을 때 직접 입력
- 대상자 변경·초기화·재업로드 시 직접 입력 주민번호 즉시 삭제
- 대장 점검 후 수정자료 엑셀 내려받기
- 화면 50:50 배치, 가로 너비 맞춤, 확대·축소, Ctrl+마우스 휠
- 증명서 페이지만 A4로 인쇄·PDF 저장
- 세 종류 기본양식 다운로드

## 날짜 처리

엑셀 날짜는 브라우저 시간대가 적용된 `Date` 객체로 바로 변환하지 않습니다. 엑셀 일련번호의 연·월·일만 복원하므로 `2024-03-01`이 `2024-02-29`로 하루 당겨지지 않습니다.

## 기본양식

업로드 영역의 `기본양식 받기`에서 다음 파일을 내려받을 수 있습니다.

- `교육공무직_일용직_경력대장_발령대장_기본양식_완성.xlsx`
- `기간제교원_발령대장_입력출력_기본양식_완성.xlsx`
- `시간강사_전문강사_발령대장_기본양식_완성.xlsx`

파일은 `templates` 폴더에 포함되어 있으며 외부 서버에서 내려받지 않습니다.

## 개인정보 처리

- 엑셀 자료는 브라우저 안에서만 처리하며 서버로 전송하지 않습니다.
- 업로드한 대장과 증명서 내용은 로컬스토리지에 저장하지 않습니다.
- 직접 입력한 주민등록번호는 이번 발급에만 사용합니다.
- 대상자를 바꾸거나 입력을 초기화하거나 새 파일을 올리면 직접 입력 번호를 삭제합니다.
- 콘솔과 오류문구에 주민등록번호 원문을 출력하지 않습니다.
- 학교명, 담당부서, 담당자, 전화번호, 기본 용도만 이 기기에 저장합니다.

## 사용 방법

1. `index.html`을 열거나 GitHub Pages에 접속합니다.
2. 경력대장 엑셀을 올리거나 체험자료를 불러옵니다.
3. 대상자와 발급할 경력을 선택합니다.
4. 주소·용도·주민번호 표시 여부를 확인합니다.
5. `인쇄 · PDF 저장`을 누릅니다.

## GitHub Pages 배포

이 폴더의 내용을 저장소 최상단에 그대로 올립니다. `templates` 폴더도 함께 배포해야 기본양식 다운로드가 작동합니다.

엑셀 읽기 라이브러리는 CDN에서 불러오지만 엑셀의 실제 데이터가 CDN으로 전송되지는 않습니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 화면·A4·인쇄 스타일
- `app.js`: 엑셀 인식, 점검, 계산, 증명서 생성
- `templates/`: 세 종류 기본양식
- `CHANGELOG.md`: 버전 변경사항
- `TEST_REPORT.md`: 테스트 결과
