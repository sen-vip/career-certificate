# 경력증명 자동화 v0.2.2

학교 행정실에서 일반 경력대장과 기간제교원 경력대장을 불러와 경력증명서를 확인하고 출력하는 정적 웹앱입니다.

## 지원 대장

### 1. 일반 경력대장

주요 열 이름은 다음과 같습니다.

- 성명
- 생년월일
- 근무부서
- 직급(위)
- 시작일
- 종료일
- 퇴직사유
- 비고
- 소정근로시간(선택)

기존 대장처럼 띄어쓰기나 일부 열 이름이 달라도 여러 별칭을 인식합니다.

### 2. 기간제교원 경력대장

다음 6개 열을 사용합니다.

- 직위(급)
- 과목
- 성명
- 생년월일 또는 주민번호
- 임용시작일
- 임용종료일

`기간제교원_경력대장_기본파일.xlsx`를 복사해 사용할 수 있습니다. 과목은 선택항목이며, 나머지 5개 항목은 필수입니다. 한 행은 하나의 연속된 임용기간입니다.

## 주요 기능

- 엑셀 업로드 후 일반 대장과 기간제교원 대장 자동 구분
- 성명·생년월일 기준 대상자 검색
- 잘못된 날짜, 종료일 누락, 기간 역전, 중복 및 기간 중첩 점검
- 일반 경력증명서 발급
- 소정근로시간 포함 경력증명서 발급
- 기간제교원 경력증명서 발급 및 과목 표시
- 주민등록번호 표시 여부 선택
- 기간제교원 퇴직사유 기본값 `계약기간 만료`
- 1~5건은 5줄, 6~10건은 10줄 서식 자동 적용
- 11건 이상은 경력사항 별지 자동 생성
- 정상 경력 전체 선택과 선택 해제
- 대장 자료 수정 후 즉시 재점검
- 수정한 대장 엑셀 내려받기
- 출력 시 작업 화면을 제외하고 증명서 페이지만 인쇄

## 주민등록번호 입력과 출력

일반 경력대장과 기간제교원 대장 모두 다음 값을 인식할 수 있습니다.

- 생년월일: `1990-01-01`, `1990.01.01`, `19900101`
- 주민등록번호: `900101-1234567`, `9001011234567`

기본 출력은 생년월일입니다. 발급 정보에서 `주민등록번호 표시 여부 → 예`를 선택하면 대장에 등록된 주민등록번호를 자동으로 불러옵니다. 대장에 번호가 없는 경우 발급 화면에서 직접 입력할 수 있습니다.

직접 입력 번호는 이번 발급의 미리보기와 인쇄에만 사용합니다. 대상자를 바꾸거나 입력을 초기화하거나 새 파일을 불러오거나 자료를 비우면 즉시 삭제됩니다. 대상자 목록과 점검 화면에는 주민등록번호 전체가 표시되지 않습니다.

## 개인정보 처리

- 엑셀 파일은 외부로 전송되지 않습니다.
- 업로드한 경력대장과 증명서 내용은 저장하지 않습니다.
- 새로고침하거나 창을 닫으면 불러온 경력자료가 사라집니다.
- 학교명, 담당부서, 담당자, 전화번호, 기본 용도만 이 기기에 저장됩니다.
- 실제 개인정보가 포함된 경력대장 파일을 GitHub 저장소에 올리지 마세요.

## 사용 방법

1. `index.html`을 열거나 GitHub Pages 주소에 접속합니다.
2. 일반 경력대장 또는 기간제교원 경력대장 엑셀을 올립니다.
3. 대상자를 선택하고 발급할 경력을 확인합니다.
4. 증명서 종류, 주소, 용도, 발급일 등을 확인합니다.
5. `인쇄 · PDF 저장`을 누릅니다.

## GitHub Pages 배포

1. 새 저장소 `career-certificate`를 만듭니다.
2. 이 폴더 안의 파일을 저장소 최상단에 올립니다.
3. GitHub 저장소의 `Settings → Pages`로 이동합니다.
4. `Deploy from a branch`, `main`, `/root`를 선택합니다.
5. 생성된 주소로 접속합니다.

엑셀 읽기 라이브러리는 CDN에서 불러옵니다. 엑셀의 실제 데이터가 CDN으로 전송되는 것은 아닙니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 화면·A4·인쇄 스타일
- `app.js`: 엑셀 인식, 점검, 계산, 증명서 생성
- `기간제교원_경력대장_기본파일.xlsx`: 기간제교원 6열 입력 기본파일
- `CHANGELOG.md`: 버전 변경사항
