# 📄 경력증명 자동화

학교 행정실에서 사용하는 경력대장을 불러와 자료를 확인하고 경력증명서를 바로 출력하는 웹 도구입니다.

교육공무직·일용직, 기간제교원, 시간강사·전문강사 경력자료를 지원하며 모든 자료는 외부 전송 없이 현재 브라우저 안에서만 처리됩니다.

현재 버전: `v0.6.0`

## ✨ 주요 기능

- 엑셀 경력대장 종류 자동 인식
- 성명·생년월일·주민등록번호를 기준으로 대상자 구분
- 발급할 경력을 건별로 선택
- 날짜 오류, 기간 역전, 누락, 중복, 경력기간 중첩 점검
- 일반 경력증명서와 소정근로시간 포함 서식 지원
- 기간제교원 및 시간강사·전문강사 경력증명서 지원
- 시간강사·전문강사 경력별 방학기간 표시 방식 선택
- 구체적인 방학기간 복수 입력, 방학 구분 선택, 연도 오타 빠른 수정, 출력 미리보기
- 5줄·10줄 서식과 11건 이상 별지 자동 생성
- 주민등록번호 표시 여부 선택
- 자료에 주민등록번호가 없을 때 이번 발급에 한해 직접 입력
- 오류 안내와 상태 배지에서 해당 경력 수정창 바로 열기
- 생년월일 누락 시 신청자 입력칸으로 바로 이동
- 대장 수정창의 한 줄 한 항목 세로 입력 방식
- 시작일·종료일 숫자 8자리 연속 입력 및 달력 선택
- 점검 후 수정한 자료를 엑셀로 다시 저장
- 증명서 미리보기 확대·축소 및 A4 인쇄·PDF 저장
- 업로드용 기본양식 3종 다운로드
- 인쇄 후 현재 발급 개인정보 자동 초기화(업로드 대장은 연속 발급을 위해 유지)
- 상단 `발급 도움말`에서 발급 순서·대상별 확인사항·개인정보 안내 확인

## 🧾 시간강사 경력 및 방학기간 표시 기준

경력증명서의 실제 항목명은 법정서식의 `근무 기간`, `근무연수`, `직급(위)`, `근무부서`를 그대로 유지합니다.

시간강사에게 필요한 세부내용은 다음과 같이 표시합니다.

- 직급(위): `시간강사(주당6시간, 총34주)`
- 교과 담당: `과목: 음악과`
- 프로그램 담당: `치어리딩`, `스포츠6+자유2` 등 담당내용 그대로 표시
- 최종직위 또는 직급: `시간강사(음악과)`

시간강사·전문강사 경력을 선택하면 경력별로 방학기간 출력 방식을 정할 수 있습니다.

- `표시 안 함`: 방학기간 문구를 출력하지 않음
- `방학기간 제외`: 직급(위) 칸에 기존처럼 짧게 표시
- `상세 기간 입력`: 시작일·종료일을 여러 건 입력하고 경력표 아래의 전용 안내 영역에 출력

상세 기간은 날짜 순서, 경력기간 범위, 중복·겹침 여부를 점검합니다. 각 기간에 여름방학, 겨울방학, 학년말·봄방학, 기타 구분을 선택적으로 붙일 수 있으며 기본값은 구분 표시 안 함입니다. 경력기간과 크게 다른 연도가 입력되고 월·일 기준으로 수정 후보가 하나뿐이면 빠른 수정 버튼을 제공합니다. 일부 기간에 오류가 있어도 정상 기간은 화면과 증명서 미리보기에 계속 표시되지만, 오류를 고치기 전에는 인쇄할 수 없습니다. 여러 시간강사 경력의 상세 기간이 함께 출력될 때는 참조번호로 경력과 안내문을 연결합니다. 이 설정은 원본 대장이나 수정자료 엑셀에 반영하지 않고 현재 발급에만 사용합니다.

## 🖥️ 사용 방법

1. 웹앱을 열고 경력대장 엑셀을 올립니다.
2. 자동으로 인식된 자료 종류와 오류 건수를 확인합니다.
3. 대상자를 선택하고 증명할 경력을 고릅니다.
4. 오류 안내를 누르면 해당 대장 항목 또는 신청자 생년월일 입력칸으로 바로 이동합니다.
5. 시간강사·전문강사는 경력별 방학기간 표시 방식을 확인하고 필요하면 상세 기간을 입력합니다.
6. 주소, 용도, 주민등록번호 표시 여부 등 발급 정보를 확인합니다.
7. 오른쪽 미리보기에서 증명서 내용을 최종 확인합니다.
8. `인쇄 · PDF 저장`을 눌러 발급합니다. 인쇄 대화상자가 열린 뒤 현재 발급 대상의 개인정보 입력값은 자동으로 정리됩니다.
9. 여러 명의 발급이 모두 끝나면 `대장 비우기`를 눌러 메모리에 남아 있는 업로드 대장을 정리합니다.

처음 사용하는 경우 업로드 영역의 체험자료로 기능을 확인할 수 있습니다.

## 📥 기본양식

업로드 영역의 `기본양식 받기`에서 다음 파일을 내려받을 수 있습니다.

- `공무직_일용직_발령대장(양식).xlsx`
- `기간제교원_발령대장(양식).xlsx`
- `시간강사_발령대장(양식).xlsx`

기본양식은 웹앱의 `templates` 폴더에 포함되어 있으며 외부 서버에서 내려받지 않습니다.

## 🔒 개인정보 처리

- 업로드한 엑셀자료는 현재 브라우저 안에서만 처리합니다.
- 엑셀파일과 경력정보는 서버로 전송하지 않습니다.
- 업로드한 대장과 성명·생년월일·주민등록번호·주소 등 증명서 개인정보는 브라우저 저장공간에 보관하지 않습니다.
- 직접 입력한 주민등록번호와 방학기간 상세값은 현재 발급에만 사용합니다.
- 인쇄 후 현재 발급 대상, 주민등록번호, 주소, 방학기간 등 현재 발급 화면의 개인정보를 자동으로 초기화합니다.
- 인쇄 후에도 업로드 대장은 다음 대상자를 연속 발급할 수 있도록 현재 탭의 메모리에만 유지합니다.
- 업무가 모두 끝나면 `대장 비우기`를 눌러 업로드 대장과 현재 발급 개인정보를 함께 정리합니다.
- 주민등록번호 원문은 오류문구나 개발자 콘솔에 출력하지 않습니다.
- 학교명, 담당부서, 담당자, 전화번호, 기본 용도만 `localStorage`에 저장할 수 있습니다.
- 콘텐츠 보안 정책(CSP)의 `connect-src 'none'`으로 앱 코드의 fetch/XHR/WebSocket/Beacon 계열 외부 통신을 차단합니다.

엑셀 읽기 라이브러리는 기존 jsDelivr의 SheetJS 0.18.5 대신 SheetJS 공식 배포처의 0.20.3을 사용합니다. 엑셀 원본 데이터는 해당 서버로 업로드하지 않습니다.

## 📅 날짜 처리

엑셀 날짜는 브라우저 시간대가 적용된 자바스크립트 날짜로 바로 변환하지 않습니다.

엑셀 일련번호에서 연·월·일만 복원하여 다음과 같은 하루 당김 오류를 방지합니다.

```text
엑셀 입력: 2024-03-01
정상 출력: 2024.03.01.
잘못된 출력: 2024.02.29.
```

윤년 날짜와 문자열 형식 날짜도 같은 기준으로 처리합니다.
