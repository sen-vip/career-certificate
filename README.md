# 📄 경력증명 자동화

학교 행정실에서 사용하는 경력대장을 불러와 자료를 확인하고 경력증명서를 바로 출력하는 웹 도구입니다.

교육공무직·일용직, 기간제교원, 시간강사·전문강사 경력자료를 지원하며 모든 자료는 외부 전송 없이 현재 브라우저 안에서만 처리됩니다.

현재 버전: `v0.7.13`



### v0.7.13 상단바 시각 위계 정리

- `외부 전송 없이 처리`는 상태 배지로 유지했습니다.
- `도움말`은 실제 조작 버튼임이 드러나는 가벼운 ghost 버튼으로 유지했습니다.
- 버전 표기는 검정 캡슐 배지에서 작은 회색 메타 텍스트로 낮췄습니다.
- `자료 비우기`를 대장을 불러온 경우에만 상단바에 표시하도록 옮겼습니다.
- 기존 업로드 영역의 중복 `자료 비우기` 버튼은 제거했습니다.

### v0.7.12 근무연한·퇴직사유 라벨 폭 회귀 수정

- v0.7.11의 좌측 구분선 고정 규칙이 요약표까지 적용되어 `근무연한`, `퇴직사유`가 잘리던 문제를 수정했습니다.
- 인적사항/경력사항/상벌사항의 12mm 기준선 정렬과 footer 안정화는 그대로 유지합니다.
- 근무연한/퇴직사유 라벨은 기존 22mm 폭을 사용합니다.

### v0.7.11 증명서 레이아웃 안정화

- 공무직·일용직처럼 `소정근로시간` 열이 있는 서식도 전체 열 폭 합을 A4 본문 폭에 맞춰 `인적사항`과 `경력사항`의 첫 세로선이 정확히 일치하도록 수정했습니다.
- 상벌표 역시 첫 구분열이 브라우저의 자동 비례확대 영향을 받지 않도록 전체 열 폭을 재정리했습니다.
- 메인 본문과 하단 발급영역을 분리해 실제 남는 높이를 계산하고, 남는 공간만 footer 위에 자동 배분합니다.
- 상벌 1건·2건·3건처럼 내용량이 변해도 담당부서 표의 하단 위치가 크게 튀지 않으며, 공간이 부족할 때만 `compact-1 → compact-2`를 적용합니다.
- 높이 계산에는 `offsetHeight`를 사용해 기본 미리보기 75% 확대/축소의 영향을 받지 않도록 했습니다.


### v0.7.9 인적사항·경력사항 좌측 기준선 정렬

- 인적사항 표에도 명시적인 `colgroup`을 적용해 좌측 구분칸을 12mm로 고정했습니다.
- 경력사항의 좌측 구분칸과 동일한 기준선을 사용해 공무직·일용직 증명서에서 보이던 어긋남을 수정했습니다.
- `nth-child()`에 의존하던 인적사항 열 폭 지정을 명시적인 열 클래스 방식으로 정리했습니다.

### v0.7.8 증명서 미리보기 기본 배율 조정
- 증명서 미리보기의 최초 배율을 75%로 변경
- 사용자가 `가로 맞춤`, +/− 버튼, Ctrl + 마우스 휠로 배율을 변경하는 기존 기능은 그대로 유지
- 인쇄·PDF 저장 시 실제 출력 크기에는 영향을 주지 않고 화면 미리보기 배율만 변경

### v0.7.7 암호 입력 오류 안내 개선
- 잘못된 암호 입력을 곧바로 ‘지원하지 않는 암호화 방식’으로 오인해 안내하던 문제를 수정했습니다.
- 첫 1~2회 실패는 `암호가 올바르지 않습니다.`로 안내하고, 입력값만 비운 뒤 같은 파일에서 바로 재입력할 수 있습니다.
- 반복 실패 시에는 암호 재확인과 미지원 암호화 가능성을 함께 안내하되, 실제 미지원 오류가 명확한 경우에만 별도 미지원 메시지를 표시합니다.
- 암호화 기능 로딩 실패(인터넷 연결 등)는 기존처럼 원인에 맞는 안내를 유지합니다.

### v0.7.6 10줄 서식 A4 맞춤
- 10줄 경력증명서에서 하단 담당부서·담당자·전화번호 영역이 잘리던 문제를 수정했습니다.
- 1~9줄 서식은 기존 디자인을 그대로 유지하고, 정확히 10줄 서식일 때만 전용 compact 레이아웃을 자동 적용합니다.
- 글자 크기는 유지하면서 경력행 높이, 제목 아래 여백, 증명문·발급일·학교명 사이 여백을 소폭 줄여 A4 1페이지 안에 맞춥니다.
- 미리보기와 실제 인쇄/PDF 저장에 동일한 레이아웃 규칙이 적용됩니다.

### v0.7.5 암호화 Excel 파일 지원
- 파일 열기 암호가 설정된 `.xlsx`를 올리면 기술 오류 대신 전용 암호 입력 창이 열립니다.
- 올바른 암호를 입력하면 브라우저 내부에서만 복호화한 뒤 기존 경력대장 분석 흐름으로 연결합니다.
- 암호는 localStorage, sessionStorage, IndexedDB, Cookie 등에 저장하지 않습니다.
- 복호화 기능은 암호 파일이 감지됐을 때만 불러와 일반 Excel 업로드 흐름을 유지합니다.
- 지원하지 않는 암호화 방식은 별도 안내하고 Excel에서 암호를 해제한 `.xlsx` 복사본 사용을 안내합니다.

### v0.7.4 제작자 표기 정리
- 상단 제목 아래의 제작자 표기를 제거해 업무용 도구처럼 더 간결하게 정리했습니다.
- 제작 정보는 페이지 하단의 작은 푸터와 도움말의 서비스 정보 영역에서만 확인할 수 있습니다.
- 푸터에서 도움말과 GitHub 저장소로 바로 이동할 수 있습니다.

### v0.7.3 경력별 방학기간 입력
- 시간강사·전문강사 경력이 여러 건 선택되면 `경력 1/N`, `경력 2/N`처럼 **경력별 방학기간 카드가 각각 생성**됩니다.
- 방학기간은 해당 경력의 시작일~종료일 범위 안에서만 검증됩니다.
- 같은 경력에 여름·겨울 등 방학이 여러 번 있을 때만 `이 경력에 방학기간 추가`를 사용합니다.
- 다른 경력의 방학기간은 다음 경력 카드에 입력합니다.

## 🔗 후속 발령 연결

실제 발령대장에서 계약기간 행과 의원면직·퇴직·계약해지 같은 후속 발령이 별도 행으로 기록된 경우를 지원합니다.

- `2012-03-01 ~ 2013-02-28` 경력 뒤에 `2012-07-17 / 의원면직` 같은 행이 있으면 후속 발령으로 감지
- 기존 경력에 자동 확정하지 않고 **경력에 반영 / 별도 발령으로 두기** 중 선택
- 경력에 반영하면 실제 종료일과 퇴직사유를 갱신
- 당초 계약 종료일은 내부적으로 보존하고 필요하면 **후속발령 반영** 배지에서 되돌리기 가능
- 연결이 어려운 자료는 임의로 합치지 않고 직접 확인하도록 안내

기본양식의 예시행은 `예) 홍길동`처럼 표시되며 웹앱 업로드 시 자동 제외됩니다.

## 🧾 시간강사 경력 및 방학기간 표시 기준

경력증명서의 실제 항목명은 법정서식의 `근무 기간`, `근무연수`, `직급(위)`, `근무부서`를 그대로 유지합니다.

시간강사에게 필요한 세부내용은 다음과 같이 표시합니다.

- 직급(위): `시간강사(주당 6시수, 총 34주)`
- 시간강사는 **경력별 주당 수업시수가 필수**이며, 누락 시 해당 경력을 선택·인쇄할 수 없습니다.
- 숫자만 입력한 주당 수업량은 기본적으로 `시수`로 출력합니다. `6시간`처럼 단위를 직접 적은 기존 자료는 입력 단위를 유지합니다.
- 교과 담당: `과목: 음악과`
- 프로그램 담당: `치어리딩`, `스포츠6+자유2` 등 담당내용 그대로 표시
- 최종직위 또는 직급: `시간강사(음악과)`

시간강사·전문강사 경력을 선택하면 경력별로 방학기간 출력 방식을 정할 수 있습니다.

- `표시 안 함`: 방학기간 문구를 출력하지 않음
- `방학기간 제외`: 직급(위) 칸에 기존처럼 짧게 표시
- `상세 기간 입력`: 시작일·종료일을 여러 건 입력하고 경력표 아래의 전용 안내 영역에 출력

상세 기간은 날짜 순서, 경력기간 범위, 중복·겹침 여부를 점검합니다. 각 기간에 여름방학, 겨울방학, 학년말·봄방학, 기타 구분을 선택적으로 붙일 수 있으며 기본값은 구분 표시 안 함입니다. 경력기간과 크게 다른 연도가 입력되고 월·일 기준으로 수정 후보가 하나뿐이면 빠른 수정 버튼을 제공합니다. 일부 기간에 오류가 있어도 정상 기간은 화면과 증명서 미리보기에 계속 표시되지만, 오류를 고치기 전에는 인쇄할 수 없습니다. 여러 시간강사 경력의 상세 기간이 함께 출력될 때는 참조번호로 경력과 안내문을 연결합니다. 이 설정은 원본 대장이나 수정자료 엑셀에 반영하지 않고 현재 발급에만 사용합니다.

## 🏅 상벌·직위해제 입력

포상·징계·직위해제는 기본적으로 `해당없음`으로 출력됩니다. 실제 사항이 있는 경우 발급정보 영역의 `상벌·직위해제 내용 입력`을 열어 항목별 `있음`을 체크하고 세부정보를 입력합니다.

- 포상: 연월일, 종류, 시행청
- 징계: 연월일, 종류, 시행청
- 직위해제: 연월일, 사유, 처분청

## 🖥️ 사용 방법

1. 웹앱을 열고 경력대장 엑셀을 올립니다.
2. 자동으로 인식된 자료 종류와 오류 건수를 확인합니다.
3. 대상자를 선택하고 증명할 경력을 고릅니다.
4. 오류 안내를 누르면 해당 대장 항목 또는 신청자 생년월일 입력칸으로 바로 이동합니다.
5. 시간강사·전문강사는 경력별 방학기간 표시 방식을 확인하고 필요하면 상세 기간을 입력합니다.
6. 주소, 용도, 주민등록번호 표시 여부 등 발급 정보를 확인합니다.
7. 오른쪽 미리보기에서 증명서 내용을 최종 확인합니다.
8. `인쇄 · PDF 저장`을 눌러 발급합니다.

처음 사용하는 경우 업로드 영역의 체험자료로 기능을 확인할 수 있습니다.

## 📥 기본양식

업로드 영역의 `기본양식 받기`에서 다음 파일을 내려받을 수 있습니다.

- `공무직_일용직_발령대장(양식).xlsx`
- `기간제교원_발령대장(양식).xlsx`
- `시간강사_발령대장(양식).xlsx`

기본양식은 웹앱의 `templates` 폴더에 포함되어 있으며 외부 서버에서 내려받지 않습니다.

## 🔒 개인정보 처리

- 업로드한 엑셀자료는 현재 브라우저 안에서만 처리합니다.
- 엑셀파일과 경력정보는 서버로 전송하지 않습니다.
- 업로드한 대장과 증명서 내용은 브라우저 저장공간에 보관하지 않습니다.
- 직접 입력한 주민등록번호는 현재 발급에만 사용합니다.
- 방학기간 표시 방식과 상세 기간도 현재 발급에만 사용하며 원본 대장에 저장하지 않습니다.
- 대상자를 변경하거나 자료를 초기화하거나 새 파일을 올리면 직접 입력한 번호를 즉시 삭제합니다.
- 주민등록번호 원문은 오류문구나 개발자 콘솔에 출력하지 않습니다.
- 학교명, 담당부서, 담당자, 전화번호, 기본 용도만 현재 기기에 저장할 수 있습니다.

엑셀 읽기 라이브러리는 CDN에서 불러오지만 엑셀의 실제 자료가 CDN으로 전송되지는 않습니다.

## 📅 날짜 처리

엑셀 날짜는 브라우저 시간대가 적용된 자바스크립트 날짜로 바로 변환하지 않습니다.

엑셀 일련번호에서 연·월·일만 복원하여 다음과 같은 하루 당김 오류를 방지합니다.

```text
엑셀 입력: 2024-03-01
정상 출력: 2024.03.01.
잘못된 출력: 2024.02.29.
```

윤년 날짜와 문자열 형식 날짜도 같은 기준으로 처리합니다.

## 🖨️ 화면과 인쇄

- 입력 영역과 증명서 미리보기를 50:50으로 배치
- 미리보기 기본 가로 너비 맞춤
- 확대·축소 버튼 제공
- Ctrl과 마우스 휠로 확대·축소
- 화면 배율과 관계없이 실제 인쇄는 A4 서식 유지
- 증명서 영역만 인쇄하거나 PDF로 저장
- 좁은 화면에서는 입력 영역과 미리보기를 위아래로 배치

## 🚀 GitHub Pages 배포

`career-certificate` 폴더 안의 파일을 저장소 최상단에 그대로 올립니다.

```text
career-certificate
├─ index.html
├─ styles.css
├─ app.js
├─ templates
│  ├─ 공무직_일용직_발령대장(양식).xlsx
│  ├─ 기간제교원_발령대장(양식).xlsx
│  └─ 시간강사_발령대장(양식).xlsx
├─ README.md
├─ CHANGELOG.md
└─ TEST_REPORT.md
```

`templates` 폴더를 함께 올리지 않으면 기본양식 다운로드가 작동하지 않습니다.

## 🗂️ 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 화면, 미리보기, A4 인쇄 스타일
- `app.js`: 엑셀 인식, 자료점검, 기간계산, 증명서 생성
- `templates/`: 업로드용 기본양식 3종
- `CHANGELOG.md`: 버전별 변경사항
- `TEST_REPORT.md`: 주요 기능 테스트 결과
