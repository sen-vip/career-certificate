# 📄 경력증명 자동화

학교 행정실에서 사용하는 경력대장을 불러와 자료를 확인하고 경력증명서를 바로 출력하는 웹 도구입니다.

교육공무직·일용직, 기간제교원, 시간강사·전문강사 경력자료를 지원하며 모든 자료는 외부 전송 없이 현재 브라우저 안에서만 처리됩니다.

현재 버전: `v0.4.0`

## ✨ 주요 기능

- 엑셀 경력대장 종류 자동 인식
- 성명·생년월일·주민등록번호를 기준으로 대상자 구분
- 발급할 경력을 건별로 선택
- 날짜 오류, 기간 역전, 누락, 중복, 경력기간 중첩 점검
- 일반 경력증명서와 소정근로시간 포함 서식 지원
- 기간제교원 및 시간강사·전문강사 경력증명서 지원
- 5줄·10줄 서식과 11건 이상 별지 자동 생성
- 주민등록번호 표시 여부 선택
- 자료에 주민등록번호가 없을 때 이번 발급에 한해 직접 입력
- 오류 안내와 상태 배지에서 해당 경력 수정창 바로 열기
- 생년월일 누락 시 신청자 입력칸으로 바로 이동
- 대장 수정창의 한 줄 한 항목 세로 입력 방식
- 점검 후 수정한 자료를 엑셀로 다시 저장
- 증명서 미리보기 확대·축소 및 A4 인쇄·PDF 저장
- 업로드용 기본양식 3종 다운로드

## 📚 지원하는 경력자료

### 교육공무직·일용직

다음 항목이 포함된 경력대장을 인식합니다.

- 성명
- 생년월일
- 근무부서
- 직종·직위 또는 직급(위)
- 고용형태 또는 급제
- 시작일
- 종료일
- 퇴직사유
- 소정근로시간
- 발령사항, 비고, 확인메모

### 기간제교원

다음 항목이 포함된 발령대장 입력자료를 인식합니다.

- 직위(급)
- 과목
- 성명
- 생년월일 또는 주민등록번호
- 임용시작일
- 임용종료일
- 호봉

호봉 항목이 없는 기존 자료도 사용할 수 있습니다.

### 시간강사·전문강사

다음 항목이 포함된 자료를 인식합니다.

- 발령일자
- 소속
- 직위구분
- 담당구분
- 담당내용
- 성명
- 생년월일 또는 주민등록번호
- 임용시작일
- 임용종료일
- 주당수업시간
- 총주수
- 방학기간 제외
- 근무시간
- 발령근거, 발령사항, 비고, 확인메모

## 🧾 시간강사 경력 표시 기준

경력증명서의 실제 항목명은 법정서식의 `근무 기간`, `근무연수`, `직급(위)`, `근무부서`를 그대로 유지합니다.

시간강사에게 필요한 세부내용은 기존 칸 안에 다음과 같이 표시합니다.

- 직급(위): `시간강사(주당6시간, 총34주)`
- 방학기간 제외: 직급(위) 다음 줄에 `방학기간제외`
- 교과 담당: `과목: 음악과`
- 프로그램 담당: `치어리딩`, `스포츠6+자유2` 등 담당내용 그대로 표시
- 최종직위 또는 직급: `시간강사(음악과)`

입력되지 않은 총주수, 방학기간 제외, 근무시간은 증명서에도 표시하지 않습니다.

## 🖥️ 사용 방법

1. 웹앱을 열고 경력대장 엑셀을 올립니다.
2. 자동으로 인식된 자료 종류와 오류 건수를 확인합니다.
3. 대상자를 선택하고 증명할 경력을 고릅니다.
4. 오류 안내를 누르면 해당 대장 항목 또는 신청자 생년월일 입력칸으로 바로 이동합니다.
5. 주소, 용도, 주민등록번호 표시 여부 등 발급 정보를 확인합니다.
6. 오른쪽 미리보기에서 증명서 내용을 최종 확인합니다.
7. `인쇄 · PDF 저장`을 눌러 발급합니다.

처음 사용하는 경우 업로드 영역의 체험자료로 기능을 확인할 수 있습니다.

## 📥 기본양식

업로드 영역의 `기본양식 받기`에서 다음 파일을 내려받을 수 있습니다.

- `공무직_일용직_발령대장(양식).xlsx`
- `기간제교원_발령대장(양식).xlsx`
- `시간강사_발령대장(양식).xlsx`

기본양식은 웹앱의 `templates` 폴더에 포함되어 있으며 외부 서버에서 내려받지 않습니다.

## 🔒 개인정보 처리

- 업로드한 엑셀자료는 현재 브라우저 안에서만 처리합니다.
- 엑셀파일과 경력정보는 서버로 전송하지 않습니다.
- 업로드한 대장과 증명서 내용은 브라우저 저장공간에 보관하지 않습니다.
- 직접 입력한 주민등록번호는 현재 발급에만 사용합니다.
- 대상자를 변경하거나 자료를 초기화하거나 새 파일을 올리면 직접 입력한 번호를 즉시 삭제합니다.
- 주민등록번호 원문은 오류문구나 개발자 콘솔에 출력하지 않습니다.
- 학교명, 담당부서, 담당자, 전화번호, 기본 용도만 현재 기기에 저장할 수 있습니다.

엑셀 읽기 라이브러리는 CDN에서 불러오지만 엑셀의 실제 자료가 CDN으로 전송되지는 않습니다.

## 📅 날짜 처리

엑셀 날짜는 브라우저 시간대가 적용된 자바스크립트 날짜로 바로 변환하지 않습니다.

엑셀 일련번호에서 연·월·일만 복원하여 다음과 같은 하루 당김 오류를 방지합니다.

```text
엑셀 입력: 2024-03-01
정상 출력: 2024.03.01.
잘못된 출력: 2024.02.29.
```

윤년 날짜와 문자열 형식 날짜도 같은 기준으로 처리합니다.

## 🖨️ 화면과 인쇄

- 입력 영역과 증명서 미리보기를 50:50으로 배치
- 미리보기 기본 가로 너비 맞춤
- 확대·축소 버튼 제공
- Ctrl과 마우스 휠로 확대·축소
- 화면 배율과 관계없이 실제 인쇄는 A4 서식 유지
- 증명서 영역만 인쇄하거나 PDF로 저장
- 좁은 화면에서는 입력 영역과 미리보기를 위아래로 배치

## 🚀 GitHub Pages 배포

`career-certificate` 폴더 안의 파일을 저장소 최상단에 그대로 올립니다.

```text
career-certificate
├─ index.html
├─ styles.css
├─ app.js
├─ templates
│  ├─ 공무직_일용직_발령대장(양식).xlsx
│  ├─ 기간제교원_발령대장(양식).xlsx
│  └─ 시간강사_발령대장(양식).xlsx
├─ README.md
├─ CHANGELOG.md
└─ TEST_REPORT.md
```

`templates` 폴더를 함께 올리지 않으면 기본양식 다운로드가 작동하지 않습니다.

## 🗂️ 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 화면, 미리보기, A4 인쇄 스타일
- `app.js`: 엑셀 인식, 자료점검, 기간계산, 증명서 생성
- `templates/`: 업로드용 기본양식 3종
- `CHANGELOG.md`: 버전별 변경사항
- `TEST_REPORT.md`: 주요 기능 테스트 결과

## 🛠️ 버전 정보

### v0.4.0

- 생년월일 미기재를 개별 경력 오류에서 분리하고 신청자 공통정보로 안내
- 생년월일 안내를 한 번만 표시하고 발급 정보의 생년월일 입력칸으로 바로 이동
- 대장 오류 문장과 경력 카드 상태 배지에서 해당 수정창 바로 열기
- 오류가 발생한 입력칸 자동 포커스·스크롤·강조
- 수정 후 오류가 남으면 모달을 유지하고 남은 오류를 다시 안내
- 대장 수정 입력폼을 데스크톱과 모바일 모두 1열 세로형으로 변경
- 긴 수정창에 고정 제목 영역과 고정 저장 버튼 영역 적용

- 시간강사 경력증명서 요약표 일부 값이 과도하게 굵게 표시되던 문제 보정
